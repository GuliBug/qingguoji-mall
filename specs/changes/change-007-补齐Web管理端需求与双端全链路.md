# change-007: 补齐 Web 管理端需求与双端全链路

## Why（为什么变更）

初版 spec.md 的管理端仅有 M-01~09 功能条目清单，缺少：
1. Web 管理端页面级需求（布局、每页字段、操作、校验、交互）；
2. 双端全链路业务流程描述（H5 买家链路 × Web 商家链路的跨端协作）。

管理端 admin.html 实现已落地，需求文档需补齐与实现对齐的规格描述，保证"需求 ↔ 代码 ↔ 测试"三者可互相对照。

## What Changes（变更内容）

- **ADDED** 3.8.1 Web 管理端页面级需求：整体框架 W-01~05（登录/布局/会话/反馈/分页）+ 六大模块页面需求 W-10~62（看板/商品/库存/订单/售后/会员），逐页定义列、操作、校验与状态 tag
- **ADDED** 第 6 章「全链路业务流程（H5 客户端 × Web 管理端）」：买家主链路 6.1、商家主链路 6.2、三条双端协作链路（6.3 仅退款 / 6.4 退货退款四段式 / 6.5 积分与会员成长）、6.6 全链路验收演示主线
- **ADDED** 验收标准 AC-15~17（Web 管理端会话与鉴权、退货退款跨端拦截与流转、双端契约对账）
- 章节顺延：原第 6/7 章改为第 7/8 章；文档版本 v2.0.0

## Impact（影响）

- 测试用例：E2E-36~46 已覆盖 AC-16/AC-17；无代码改动
- 后续 plan/tasks/测试用例引用编号新增 W-xx 系列
