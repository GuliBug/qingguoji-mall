> 对应工程：`frontend-h5/mall-client/`（Taro 4 + Vue3 + TypeScript + Vite）
> 实现状态：**已完成**（生产构建已验证通过，详见《05-测试方案与报告》）

## 1. 技术栈与工程结构

| 项 | 选型 | 说明 |
|---|---|---|
| 框架 | Taro 4.3 + Vue3 | 一套代码可编译 H5 / 微信小程序 |
| 语言 | TypeScript 5.6 | 接口与页面全部 `.vue` + `<script setup>` |
| 构建 | Vite 5 + @tarojs/cli | `npm run dev:h5` / `npm run build:h5` |
| 样式 | SCSS | 组件内 scoped 样式为主 |
| 网络 | Taro.request 封装 | 见 `src/api.ts` |

```
src/
├── app.config.ts          # 页面注册 + tabBar + 导航栏主题（品牌红 #B0231F）
├── api.ts                 # 接口封装（唯一网络出口，含 BASE 自适应策略）
└── pages/
    ├── index/             # 首页（商品列表）
    ├── product/           # 商品详情（SKU 选择、加购/立即购买）
    ├── cart/             # 购物车（改数量、结算下单、支付）
    ├── orders/           # 订单（状态 tab、支付/取消/确认/售后）
    └── member/           # 会员中心（积分、签到、扫码、流水）
```

> 工程内无独立 store / router（Taro 页面即路由），状态以页面 `ref` 局部管理；
> 登录态 token 存于 Taro 本地存储（`qgj_token`），请求统一携带 `X-Token`。

## 2. 网络层设计（src/api.ts）

### 2.1 BASE 自适应策略
为避免上服务器时改代码，BASE 由 `resolveBase()` 按当前 host 推导：

| 当前域名 | BASE | 说明 |
|---|---|---|
| `localhost` / `127.0.0.1` | `http://localhost:8080` | 本地开发直连后端 |
| 其它（线上域名） | `''`（空） | 走 Nginx 同域反代，请求自然拼成 `/api/xxx` |
| 小程序端（无 `window`） | `''` | 实际需在小程序后台配置后端域名白名单 |

### 2.2 统一 request 封装
```ts
async function request<T>(method, path, data?): Promise<T> {
  const res = await Taro.request({
    url: BASE + path, method, data,
    header: { 'Content-Type': 'application/json', 'X-Token': getToken() }
  })
  return res.data as T   // 后端返回 { code, msg, data }，前端直接消费
}
```
- 所有接口通过 `api` 对象暴露（成员：`login / me / checkin / scan / pointsLogs / products / productDetail / cart / addToCart / updateCart / createOrder / pay / cancel / confirm / orders / applyAfterSale / myAfterSales`）。
- 调用方判断 `res.code === 200` 表示成功，否则 `res.msg` 提示。

## 4. 页面设计

### 4.1 首页 `pages/index`
- 顶部品牌栏 + 商品卡片列表（grid）。
- 数据：`api.products()` → `res.data.content`（Spring Page 结构）。
- 交互：点击卡片 `goDetail(p.id)` 跳转详情；空数据占位「加载中…」。

### 4.2 商品详情 `pages/product`
- 数据：`api.productDetail(id)` → 商品信息 + `skus[]`。
- SKU 选择：规格 chip 列表，选中项高亮；缺货判断 `totalStock - lockedStock > 0`。
- 数量步进器（最小 1）。
- 操作：
  - **加入购物车** → `api.addToCart(selectedSku.id, qty)`
  - **立即购买** → 先 `addToCart` 再跳购物车（同 Web 简化链路）

### 4.3 购物车 `pages/cart`
- 数据：`api.cart()` → 购物车项列表（含 SKU 名称/单价/数量）。
- 改数量：`api.updateCart(cartId, qty)`。
- 结算（关键）：
  ```ts
  const order = await api.createOrder(
    lines, '张三', '13800001111', '湖南省长沙市岳麓区青果大厦8F')
  await api.pay(order.data.orderNo)
  ```
  > ⚠️ **演示限制**：收件人姓名/电话/地址在代码里**硬编码**为固定值，
  > 未做收货信息录入表单。生产化需补充地址管理模块。

### 4.4 订单 `pages/orders`
- 状态 tab：`全部 / 待付款 / 待发货 / 待收货 / 已完成 / 已取消`。
- 状态中文映射：`WAIT_PAY→待付款、PAID→待发货、SHIPPED→待收货、COMPLETED→已完成、CANCELED→已取消、AFTER_SALE→售后中`。
- 订单卡片展示：实付金额、运费、本次获得积分。
- 操作按钮随状态变化：
  | 状态 | 按钮 |
  |---|---|
  | `WAIT_PAY` | 支付 / 取消（取消后释放库存） |
  | `SHIPPED` | 确认收货 |
  | `PAID/SHIPPED/COMPLETED` | 售后 |
- 申请售后：`type = 未发货→REFUND_ONLY，已发货→RETURN_REFUND`；数量上限 `it.qty - it.afterSaleQty`。

### 4.5 会员中心 `pages/member`
- 顶部展示：`me.points`（可用积分）、`me.pointRate`（积分倍率）。
- 功能入口：
  - **每日签到** → `api.checkin()`（+5 积分，断签重置连签天数）
  - **扫码积分** → 调起扫码 → `api.scan(code)`（+10 积分/包，校验防伪码有效性）
  - **积分明细** → `api.pointsLogs()`（弹窗展示最近流水）
- 会员等级说明弹窗（铜/银/金/黑金 阈值与权益，与后端 `Member` 等级算法一致）。

## 5. 前后端契约（H5 侧依赖的字段）

| 后端返回 | H5 消费位置 | 说明 |
|---|---|---|
| `data.content`（数组） | 首页列表 | Spring `Page` 结构 |
| `data.skus[]` | 详情 SKU | 含 `id/spec/price/totalStock/lockedStock` |
| `data.orderNo` | 支付 | 下单后返回 |
| `o.freight / o.pointsEarned` | 订单卡片 | 运费 / 获得积分 |
| `it.afterSaleQty` | 售后数量上限 | 已售后数量 |
| `me.points / me.pointRate` | 会员中心 | 积分与倍率 |

> H5 **不依赖**管理端的 `TableDataInfo`，只消费 `/api/**` 的 `Page` 结构，
> 因此后端重构时 `/api/**` 列表保持 `content/totalElements` 未被改坏。

## 6. 已知 Demo 限制（生产化清单）

1. **自动登录硬编码**：首页写死手机号+验证码，无登录 UI。
2. **收货信息硬编码**：购物车结算时收件人/地址写死。
3. **封面图占位**：`coverFor(name)` 用占位图，无真实商品图资源。
4. **无地址/优惠券/支付渠道选择**：下单直接走「创建→支付」两步。
5. **H5 包体偏大**：`common.js` 约 21MB（gzip 15.9MB），首屏慢，需 chunk 拆分。

## 7. 与 Web 管理端的差异

| 维度 | H5 客户端 | Web 管理端 |
|---|---|---|
| 框架 | Taro + Vue3（跨端） | Vue3 + Element Plus（纯 Web） |
| 用户 | 普通会员（MEMBER token） | 管理员（ADMIN token） |
| 接口前缀 | `/api/**` | `/admin-api/**` |
| 状态管理 | 页面局部 ref | Pinia + 动态路由 |
| 鉴权 | 自动演示登录 | 登录页 + 路由守卫 |
| 构建产物 | `dist/h5` | `dist/web` |
