# change-006: 双端联调测试补齐

## Why（为什么变更）

第二轮字段级测试后仍存在两类覆盖缺口：
1. 售后「退货退款」完整链路（申请→审核→买家寄回→商家确认收货→库存回补+积分扣回）无端到端验证；
2. Web 管理端没有前端页面，`/admin-api` 14 个接口没有 UI 调用方，考评要求的"客户端+管理端"中管理端无法演示。

## What Changes（变更内容）

- **ADDED** `specs/Web管理端模块/spec.md`：若依风格管理端页面（admin.html，后端同源托管），覆盖看板/商品/库存/订单/售后/会员六大模块与全部 14 个 admin-api 接口
- **ADDED** `specs/前后端联调/spec.md`：双端联调验收（H5 五页面模块编译可达、api.ts 15 个接口契约对账、退货退款全链路 8 个 E2E 用例）

## Impact（影响）

- 代码：修复 `fillReturnLogistics` 空物流单号缺陷（10 号缺陷）；新增 admin.html
- 测试：E2E 由 35 例扩至 46 例，总量 71/71 全通过
